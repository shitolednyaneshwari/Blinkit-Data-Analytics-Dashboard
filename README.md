# Blinkit-Data-Analytics-Dashboard
## 📊 Project Overview
This project is a Power BI Data Analytics Dashboard created to analyze Blinkit's sales performance and outlet information.
The dashboard provides insights into sales, products, outlet types, outlet sizes, outlet locations, fat content, customer ratings, and outlet establishment trends.
## 🎯 Objectives
- Analyze overall sales performance
- Understand sales by outlet type and outlet size
- Analyze different item categories
- Compare low-fat and regular-fat products
- Analyze outlet establishment trends over the years
- Understand customer ratings
- Create an interactive Power BI dashboard
## 🛠️ Tools & Technologies
- Power BI
- Power Query
- Microsoft Excel / CSV
- Data Cleaning
- Data Visualization
- Data Analysis
## 📌 Key KPIs
The dashboard includes:
- Total Sales
- Average Sales
- Number of Items
- Average Rating
## 📈 Dashboard Features
### 1. Sales Analysis
The dashboard displays total and average sales using interactive KPI cards.
### 2. Outlet Analysis
Sales are analyzed based on:
- Outlet Type
- Outlet Size
- Outlet Location Type
### 3. Product Analysis
The dashboard provides insights into different item categories such as:
- Fruits and Vegetables
- Snack Foods
- Household
- Frozen Foods
- Dairy
- Canned
- Baking Goods
- Health and Beauty
- Meat
- Soft Drinks
### 4. Fat Content Analysis
Products are categorized into:
- Low Fat
- Regular
### 5. Outlet Establishment Analysis
A time-series visualization shows outlet establishment trends across different years.
### 6. Interactive Filters
Users can filter the dashboard using:
- Outlet Location Type
- Outlet Size
- Item Type
